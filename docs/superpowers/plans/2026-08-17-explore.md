# Explore page implementation plan

Spec: `docs/superpowers/specs/2026-08-17-explore-design.md`
Files: `src/routes_web.py`, `src/storage_mongo.py`,
`templates/dashboard_layout.html`, `templates/partials/icons.html`,
`templates/dashboard/explore.html`, `templates/dashboard/explore_project.html`,
`static/css/explore.css`, `static/js/dashboard.js`, `static/js/i18n-data.js`,
`README.md`, `tests/`. Backend storage reads for Explore already exist as
uncommitted WIP — this plan finishes them as a signed-in dashboard feature.

## Step 1 — storage_mongo.py: sparse unique publicId index

`INDEXES['projects']` gains `([('publicId', ASCENDING)], True, {'sparse': True})`.
Extend the tuple format with an optional options dict:

- `ensure_indexes`: unpack `keys, unique` + optional options; give
  option-carrying indexes an explicit name (Mongo auto-names by key pattern
  alone, so changing options on an existing index raises
  `IndexKeySpecsConflict` code 86); omit `name` when unused (mongomock treats
  a literal `name=None` as a distinct index).
- `tests/test_storage_mongo.py::test_indexes_cover_every_declared_collection`:
  unpack the same way.

This fixes the failing `test_save_then_load_round_trips` (E11000 duplicate
null key on projects without `publicId`).

## Step 2 — routes_web.py: move Explore under /dashboard

- Delete the public `/explore` + `/explore/projects/<public_id>` routes and
  the sitemap entry (private pages must stay out of sitemap/robots).
- Add `/dashboard/explore` + `/dashboard/explore/projects/<public_id>`, both
  `@login_required`, rendering `dashboard/explore.html` /
  `dashboard/explore_project.html`. Filtering/pagination logic unchanged.
- `_public_projects()` stays: `None` for SessionStorage → 503 unavailable.

## Step 3 — dashboard chrome

- `templates/partials/header.html`: remove the public Explore nav link.
- `templates/dashboard_layout.html`: sidebar Explore entry (after Projects,
  `side.explore`, active on `/dashboard/explore*`) + a `{% block styles %}`
  after the shared stylesheets so page-specific CSS can be injected.
- `templates/partials/icons.html`: add a `compass` glyph.

## Step 4 — templates

`templates/dashboard/explore.html` and `explore_project.html` extend
`dashboard_layout.html` (blocks: title, page_title, page_subtitle, styles,
content). Delete the old public `templates/explore*.html`. `static/css/explore.css`
drops the public-page chrome rules (`.explore-main*`, `.explore-header`).

## Step 5 — static/js/dashboard.js: publication fieldset

- `saveProjectFields`: add `category` and `isPublic` to the body.
- `prepareEditProject` / `prepareNewProject`: prefill/reset both; enable
  `#projectPublication` only when `project.status === 'Shipped'`.

## Step 6 — i18n + README

- `static/js/i18n-data.js`: add `side.explore` to all 12 languages; remove the
  now-unused `nav.explore`; keep `explore.*` (en only, fallback English).
- Run `scripts/split_i18n_data.py` to regenerate `static/js/i18n/*.js`.
- `README.md`: `/dashboard/explore` rows (auth required), reworded feature
  bullet.

## Step 7 — tests

- `tests/test_explore.py`: unauthenticated → redirect; no-club auth_client →
  `/dashboard/welcome`; session mode → 503; mocked shared backend (with
  `list_public_projects`/`load`/`load_lite`/`resolve_club_key`/
  `get_user_record`) renders cards, filters, pagination clamp, empty state,
  detail 200/404; sitemap excludes `/explore`; publish gating (non-Shipped,
  missing category, invalid category, unpublish, new-project defaults).
- `tests/test_storage_mongo.py`: sparse index allows missing `publicId`,
  rejects duplicates; `list_public_projects` filters + narrow projection;
  private-directory clubs excluded.
