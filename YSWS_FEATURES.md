# Hack Club YSWS (You Ship, We Ship) Features

Features found across Hack Club's YSWS programs — events where teens build projects and Hack Club ships rewards in return. These are program-level features, not website/platform features.

---

## Core YSWS Mechanics

- **Build-to-earn model** — You ship a project (code, CAD, hardware, art), we ship you a prize
- **Open-source requirement** — Projects must be published publicly (GitHub, gallery, etc.)
- **No-experience-required onboarding** — Guided tutorials, workshop decks, and step-by-step docs for complete beginners
- **Free for teens 13–18** — Funded by Hack Club's 501(c)(3) nonprofit and corporate donors (NASA, AMD, GitHub, etc.)
- **Parental waiver collection** — U18/O18 waiver flows for liability and shipping
- **School enrollment verification** — Some programs (OnBoard, Cider) required proof of high school enrollment
- **No double-dipping rule** — Same project can't count for multiple YSWS programs simultaneously
- **Anti-cheat human review** — Submitted hours/projects reviewed by real people before approval
- **AI usage caps** — Some programs limit AI-generated code to 30% max, ban AI art entirely

## Discovery & Onboarding

- **Toolbox directory** (`toolbox.hackclub.com`) — Central catalog of all YSWS programs
- **Program card grid** — Each program has a card with logo, description, type, deadline, reward preview
- **Tag-based filtering** — Filter by category: Web, CAD, Hardware, Games, Music, Travel, etc.
- **Full-text search** — Search programs by title and description
- **Dedicated subdomain per program** — Each YSWS lives at its own `*.hackclub.com` (stardance.hackclub.com, sprig.hackclub.com, etc.)
- **Program detail pages** — Full description, requirements, reward tiers, submission guide, FAQ
- **Getting-started guides** — Tutorials on jams.hackclub.com, workshops.hackclub.com, and per-program docs
- **YouTube playlists** — Video walkthroughs for PCB design, game dev, and other skills
- **"Create Your Own YSWS"** — Club leaders can design custom programs at project.hackclub.com
- **All YSWS Programs nav link** — Links to ysws.hackclub.com from club dashboards
- **Homepage showcase strip** — 4 featured programs displayed on the landing page

## Submission & Tracking

- **GitHub PR-based submission** — Fork a repo, add project folder with README, open a pull request
- **Google Forms submission** — Alternative submission path for simpler programs (Boba Drops, Typeface)
- **Dedicated web platform submission** — Custom-built submission portals (Sprig editor, Stardance platform)
- **Hackatime time tracking** — Log coding hours automatically via WakaTime-based integration
- **Lapse time tracking** — Log hardware/art hours separately from coding hours
- **Slack bot timer** (`/hack` command) — Historical method: start/stop timers in Slack, log hours, submit scraps
- **GitHub README.md requirement** — Every submission must include a README describing the project
- **Hosted demo requirement** — Projects must be playable/usable/testable (GitHub Pages, Vercel, itch.io, TestFlight)
- **Screenshot/commit-link scraps** — Arcade-era: submit proof of work via Slack scrapbook
- **Peer review/rating system** — Stardance: other teens rate your project; rating determines reward amount
- **Approval workflow** — Admins review Submitted projects before marking them Shipped (club dashboard)
- **Submission gallery** — Public showcase of all submitted projects (Sprig: 800+ games, Hackaccino: 3D sites)

## Rewards & Shipping

- **Stardust currency shop** (Stardance) — Earn currency per hour + peer rating bonus; spend on prizes
- **Ticket economy** (Arcade) — 1 ticket per hour; prize tiers at escalating ticket counts
- **Hours-as-balance shop** (OneKey, Calculate) — Tracked hours become spendable balance
- **Flat reward per submission** — Build one thing → get one thing (Sprig console, Boba grant, Frappuccino)
- **Tiered rewards** — More hours = better prizes (Tailor: 3h sticker → 8h sewing kit → 40h sewing machine)
- **Cash grants** — Virtual credit cards for purchasing parts/tools (OnBoard $100 PCB grant, Outpost $1000, Fallout funding)
- **Apple/Google Play store grants** — Cider: $100 Apple Developer Membership + $50 gift card for publishing
- **Domain grants** — Free custom domains for hosting projects (Reactive, iplace)
- **Travel rewards** — Flights to hackathons in other countries (Macondo → Bogota, Beest → Netherlands, Horizons → 7 countries)
- **Conference exhibits** — Outpost: exhibit at Open Sauce conference
- **Special category prizes** — Calculate: Best music (musical calculator), Worst calculator (abacus), Cutest project (tamagotchi)
- **Physical hardware kits** — Pre-assembled kits mailed to builders (Sprig console, Blot drawing machine, BLARE alarm clock)
- **Build-it-yourself kits** — Unassembled parts + guide (Blot: 3D-printed parts + aluminum + custom board)
- **Custom swag** — Sticker packs, t-shirts, plushies, pillowcases, keycaps for milestone achievements
- **Food & drink grants** — Boba, ice cream, Frappuccino, pizza for clubs, junk food
- **Stackable grants** — Multiple small grants add up (Boba: $5/site, Tailor: $2.50/hour for fabrics)
- **Streak bonuses** — Tee'd Up: build a site 7 days straight → earn a Boba Drops t-shirt
- **Hardware dev-kit reuse** — Sprig and Blot parts are standard components you can repurpose for other projects
- **Regional pricing** — Stardust costs vary by country (adjusted for local purchasing power)

## Gamification

- **Peer rating system** — Stardance: teens rate each other's projects; higher ratings = more stardust
- **Progress ladder** — Prize tiers create escalating goals (Arcade: 1 ticket → 400 tickets for Framework laptop)
- **Streak challenges** — Consecutive-day-building unlocks bonus rewards
- **Time pressure** — Deadlines create urgency (most summer programs run 2-4 weeks)
- **Shop system** — Browse a catalog of prizes, save up currency, redeem when ready
- **Category voting** — Community votes on "best music," "worst calculator," "cutest project"
- **Club leveling** — Individual ships contribute to club-wide levels (4 shippers → Level 2, 8 ships → Level 3)
- **Level perks** — Higher club levels unlock sticker orders, monthly mail, premium recognition
- **Level decay** — Clubs that stop shipping drop back a level after 6 months
- **Scrapbook showcase** — Public project gallery creates social motivation (Arcade-era)
- **Weekly drops & freebies** — Stardance: rotating limited-time offers and surprise rewards
- **AMA callbacks** — Special guests (astronauts, CEOs) create FOMO and prestige

## Program Management & Admin Tools

- **Event approval workflow** — Submitted events go to a private Slack channel for review before publishing
- **Admin project review queue** — Dashboard showing all Submitted projects awaiting approval across all clubs
- **Approve/Reject actions** — One-click to mark projects Shipped (counts toward levels) or Draft (sent back)
- **Attendee list management** — Event creators can view full attendee lists with names, emails, Slack IDs
- **Attendee exports** — Export as CSV, JSON; copy names/emails/Slack IDs only; copy full tab-separated list
- **`/create-event` Slack command** — Community members can propose events via Slack modal form
- **Project status pipeline** — Draft → Submitted → Shipped (or rejected back to Draft)
- **Club level tracking** — Dashboard shows current level, progress percentage, ships needed to level up
- **Distinct shipper counting** — Level 2 requires 4+ different members to ship (not just 4 total ships)
- **Pending ships count** — Metric showing how many projects are awaiting admin review
- **CSRF protection** — All mutation endpoints require valid CSRF tokens
- **Role-based authorization** — Leaders/Mentors create/edit/delete; Members can only RSVP and submit
- **State persistence** — Session cookie (2.8KB cap), Airtable, or Mongo (`STORAGE_BACKEND`) for data storage
- **Stale-while-revalidate** — Client caches state in localStorage, refreshes from API in background

## Tools & Infrastructure

- **Custom web-based editors** — Sprig game editor (CodeMirror + Preact), Blot art editor (split-screen code/visualizer)
- **Hackatime integration** — Automatic time tracking for coding hours (WakaTime-based)
- **Lapse integration** — Time tracking for hardware/art hours
- **HCB virtual credit cards** — Issued for grants (OnBoard, Outpost); spendable anywhere online
- **GitHub Actions automation** — Auto-label PRs, auto-close stale submissions, auto-assign reviewers
- **Open source everything** — Editors, engines, firmware, PCB designs, 3D-printable cases all on GitHub
- **ISR (Incremental Static Regeneration)** — Event pages revalidate every 1-5 seconds for near-real-time updates
- **Slack emoji rendering** — `:emoji:` shortcodes in descriptions replaced with images via Badger API
- **Dynamic OG image generation** — Per-program social cards via workshop-cards.hackclub.com
- **Accessibility** — prefers-reduced-motion support, mobile-responsive layouts, 44px touch targets
- **Dark mode** — All program pages support dark/light theme toggle
- **Local time display** — All dates/times auto-adjusted to the viewer's browser timezone
